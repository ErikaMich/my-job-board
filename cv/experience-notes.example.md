# Experience notes (example)

Copy this file to `experience-notes.md` in the same `cv/` folder and fill it
with the detailed background the tailored-CV summary should draw from. It's
optional — if `experience-notes.md` doesn't exist, the Custom CV feature falls
back to `CANDIDATE_PROFILE` in `config.js` alone.

Be far more specific here than in `CANDIDATE_PROFILE`: exact metrics, tool
names, and project stories. The one-page CV and the short fit-scoring profile
both leave most of this out, so this is where the rich detail lives.

## Roles
- **Job Title, Company (20XX–20XX)** — what you owned, who you worked with, the
  problems you solved, and the measurable outcomes (e.g. "cut checkout drop-off
  32%", "shipped design system used by 40 engineers").

## Skills & tools
- Design: Figma, prototyping, design systems, …
- Research: usability testing, interviews, …
- Other: front-end familiarity, data/analytics, …

## Notable projects
- **Project name** — the situation, what you did, and the result. Concrete
  numbers make the generated summary stronger.
